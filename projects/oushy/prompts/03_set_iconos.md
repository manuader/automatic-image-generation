# 03 — Set de 9 íconos del sistema

- **estado**: hecho

## Prompt

Match EXACTLY the drawing style of the four icons in the attached reference: hand-drawn single-weight outline, thick rounded stroke ends, slightly wobbly imperfect line as if drawn with a marker, dark olive-grey #54574F stroke, with one small orange #EA6330 8-pointed star as the accent inside or beside each icon. Same studio, same icon family. Draw a sheet of NINE new icons for a creative studio, arranged on a clean 3 by 3 grid with equal generous spacing, on a flat cream #F6EFE9 background, square 1:1 image. The nine subjects, one per cell, reading left to right and top to bottom: a lightbulb, a camera, a megaphone, a pencil drawing a line, a smartphone showing a feed, a calendar, a chat bubble, a rocket, and a handshake. Every icon uses the same stroke weight and occupies the same optical size. No frames around the cells, no text, no labels, no shadows.
